PDF para Word BETA

Usa uma versão do LibreOffice compilada pra rodar inteiramente no seu navegador (via WebAssembly) — o mesmo motor por trás do "Abrir como Word" de verdade, não uma extração de texto aproximada.

⚠️ Recurso experimental — leia antes de usar:
  • Baixa um componente pesado (150–250 MB) na hora de converter, só na primeira vez da sessão.
  • Pode levar de 10 a 20 segundos só pra inicializar, antes de começar a converter de verdade.
  • Precisa que o site esteja hospedado num servidor com os cabeçalhos HTTP corretos (COOP/COEP) — não funciona abrindo o arquivo .html direto do computador. No GitHub Pages (que não permite configurar cabeçalhos), incluí um arquivo coi-serviceworker.js que resolve isso — ele precisa estar na mesma pasta do .html publicado. Na primeira visita, a página recarrega uma vez sozinha — é esperado, não é erro.
  • Essa integração específica não pôde ser testada de ponta a ponta — é melhor esforço.
🚫 Este ambiente não tem isolamento de origem cruzada (COOP/COEP) ativo. Se você estiver no GitHub Pages, confira se o arquivo coi-serviceworker.js está na mesma pasta do .html publicado. Se estiver abrindo o arquivo direto do computador, essa ferramenta não vai funcionar aqui — publique o site pra usá-la.

OCR — tornar pesquisável

Pega um PDF escaneado (só imagem) e devolve o mesmo arquivo, com a mesma aparência, mas com uma camada de texto invisível por cima — passa a ser selecionável e pesquisável.

Arraste um PDF escaneado aqui
ou clique para escolher o arquivo
O reconhecimento roda no seu navegador e pode demorar — de alguns segundos a alguns minutos por página, dependendo do tamanho do PDF e do computador. Não feche esta aba enquanto processa. A qualidade depende de como o documento foi escaneado: quanto mais nítido e reto, melhor o resultado. Se uma página específica der erro, ela é incluída sem a camada de texto pesquisável, sem travar o restante do arquivo.
